# 每日小计划

一个自用 + 给好朋友用的微信小程序：按星期循环的每日计划，逐项勾选打卡，全部完成时面包超人会跳出来为你庆祝。

## 功能

1. **设定计划**：周一到周日各一套循环模板，手动添加或批量导入
2. **今日打卡**：自动带出当天计划，点圆圈勾选；当前时段高亮「进行中」、超时未完成标「错过啦」；进度条 + 连续打卡天数
3. **导入计划**：把备忘录里的计划整段粘贴进来，自动识别星期标题和时间（`7.50-8.30 刷教综客观题` 这种写法）；下午写成 `6.40` 会自动按 18:40 处理
4. **朋友互看**：互相绑定邀请码后，可以看到对方今天的打卡进度

## 首次配置（约 5 分钟）

1. 微信开发者工具 → 导入本仓库根目录，`project.config.json` 里的 `appid` 改成自己的小程序 AppID
2. 工具栏点「云开发」→ 开通（免费额度自用足够）→ 记下环境 ID；如果只有一个环境，`miniprogram/env.js` 可留空，多个环境则填入目标环境 ID
3. 云开发控制台 → 数据库 → 新建 3 个集合：`templates`、`records`、`binds`，权限都选「仅创建者可读写」
4. 右键 `cloudfunctions/login` → 「上传并部署：云端安装依赖」；`cloudfunctions/friendToday` 同样操作
5. 编译运行，完成

## 给朋友用（不用上架）

1. 小程序后台（mp.weixin.qq.com）→ 管理 → 成员管理 → 把朋友加为「体验成员」
2. 开发者工具点「上传」→ 后台「版本管理」把该版本设为「体验版」→ 朋友扫体验版小程序码即可使用
3. 互看进度：「朋友」页复制自己的邀请码发给对方，对方粘贴并起昵称即完成绑定；互相绑定就能互看

## 隐私与版权说明

- 数据隔离：`templates`、`records` 仅本人可读写；朋友进度只能由云函数在校验绑定关系后读取，邀请码（openid）不公开、不可猜测，发给谁即授权谁
- 吉祥物为纯 WXSS 原创手绘（圆脸红鼻子的面包小人风格），未使用任何版权图片；想换真实图片可自行替换 `miniprogram/components/anpanman`
