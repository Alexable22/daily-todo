# 每日小计划

一个自用的微信小程序：按星期循环的每日计划，逐项勾选打卡，全部完成时面包超人会跳出来为你庆祝。

## 功能

1. **设定计划**：周一到周日各一套循环模板，手动添加或批量导入
2. **今日打卡**：自动带出当天计划，点圆圈勾选；当前时段高亮「进行中」、超时未完成标「错过啦」；进度条 + 连续打卡天数
3. **导入计划**：把备忘录里的计划整段粘贴进来，自动识别星期标题和时间（`7.50-8.30 刷教综客观题` 这种写法）；下午写成 `6.40` 会自动按 18:40 处理

彩蛋与互动：戳一戳今日页右上角的面包超人，它会回弹并冒出一句打气的话；双击它比心、长按搓搓会冒小爱心，还能整个拖走（松手会像不倒翁一样弹回来摇两下）；它平时会轻轻呼吸、偶尔歪头蹦跳转个圈，也会按时段主动找你说话（清晨打气、深夜劝休息）；23 点后会弹出晚安卡劝睡，傍晚起页头有星星亮起。任务可以双击「拍一拍」把它拍醒；勾选有小概率触发「暴击」横幅；连击满 7/30/100 天时超人会变身放烟花庆祝；偶尔断签一天没关系，每月一张「超人守护卡」会自动护住连击；昨天全部完成的话，今天会收到一张超人寄来的旅行明信片，可以收藏。

## 首次配置（约 1 分钟）

1. 微信开发者工具 → 导入本仓库根目录，`project.config.json` 里的 `appid` 改成自己的小程序 AppID
2. 编译运行，完成

数据全部存在手机本地（`tpl_1`~`tpl_7` 为星期模板，`rec_日期` 为每日勾选记录），无需云开发、无需任何费用；注意卸载微信或清理缓存会丢失数据。

## 隐私与版权说明

- 纯本地存储，数据不离开手机，没有任何网络请求
- 吉祥物使用面包超人图片素材（`miniprogram/assets/mascot/`，由手机截图裁切，可用 `scripts/build-mascot-assets.py` 重新生成），**仅限个人自用**：不要上架小程序、不要把本仓库转为公开。组件 `miniprogram/components/anpanman` 不传 `src` 时仍渲染纯 WXSS 原创手绘脸，需要规避版权时去掉 `src` 属性即可
- 本仓库早期版本基于微信云开发、支持朋友互看打卡（见 git 历史），需要时可以从历史中恢复
